# Sample Audio and Testing Material

The application was tested using different types of audio files to evaluate its transcription and translation capabilities under varied conditions.

## Types of Audio Used

The testing material included:

- General English audio recordings for testing standard English transcription.
- Audio recordings in multiple languages to test multilingual transcription and translation.
- YouTube videos converted to MP3 format and then used as audio input for testing.
- Long screen recordings converted to MP3 and used to test the application's ability to process longer audio files.

## Purpose of Testing

Using different types of audio helped evaluate how the application performed across different languages, audio lengths, and recording sources.

The testing also helped identify limitations in transcription accuracy, particularly with multilingual and mixed-language audio.

## Note

The original audio files used during testing are not included in this repository. Some of the material was obtained from publicly available online sources, and the files are not necessary for understanding or running the application.

The sample folder therefore documents the types of testing material used rather than redistributing the original audio files.
