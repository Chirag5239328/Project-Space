# Kwick Kravings

## Project Overview

Kwick Kravings is a food ordering website developed as an academic web development project.

The project was created as part of a team assignment that required us to develop a web application using technologies such as Django and React. The application was designed to simulate the basic workflow of an online food ordering platform.

## Features

The website includes different sections and functionalities such as:

- Home page
- About Us
- Address management
- Food ordering interface
- Shopping cart
- Checkout
- Navigation between different sections of the application

The project demonstrates the basic flow of selecting food items, managing a cart, providing an address and proceeding towards checkout.

A payment gateway was not integrated into the project.

## My Role
