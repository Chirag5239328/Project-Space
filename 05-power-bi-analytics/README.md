# Power BI Business & HR Analytics Dashboards

## Overview

This project contains two interactive Power BI dashboards developed independently to explore data analysis, business intelligence, data visualization, and DAX.

The project consists of:

1. **HR Analysis Dashboard**
2. **Business Analysis Dashboard**

Both dashboards were created as self-directed projects during my third year of undergraduate study. They were not formal academic assignments. I created them to explore the capabilities of Power BI, gain practical experience working with real-world datasets, and strengthen my data-analysis and visualization skills.

The HR dashboard was developed first. After gaining familiarity with Power BI through the HR dataset, I created the Business Analysis Dashboard using a Superstore dataset. The second dashboard involved deeper exploration of DAX and business-oriented analysis.

The experience gained through these projects later became useful during my internship at FedEx, where I worked on Power BI dashboards and more advanced interactive functionality.

---

# Project Objectives

The main objectives of these projects were to:

- Explore Microsoft Power BI beyond basic classroom exposure.
- Learn how to transform raw datasets into interactive dashboards.
- Develop practical experience with DAX.
- Create calculated columns and measures.
- Identify patterns and trends in structured datasets.
- Practice presenting data through appropriate visualizations.
- Understand how different datasets can be analyzed from multiple perspectives.
- Develop business-oriented data analysis skills.
- Build practical experience that could be applied to professional data-analysis work.

# Dashboard 1: HR Analysis Dashboard

## Overview

The HR Analysis Dashboard was the first Power BI dashboard I created.

The project used an HR dataset containing employee-level information related to demographics, employment, compensation, satisfaction, performance, work experience, career progression, and attrition.

This project represented the next stage of my Power BI learning.

While the HR dashboard helped me become familiar with Power BI and DAX, the Superstore project involved deeper exploration of DAX and business-oriented analysis.
